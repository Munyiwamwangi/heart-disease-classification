# Heart Disease Classification

A machine learning web application that predicts the likelihood of heart disease using patient clinical data.

## Features
- Logistic Regression model
- Streamlit web interface
- Real-time predictions
- Simple and lightweight deployment

## Technologies
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## Running Locally

```bash
pip install -r requirements.txt
streamlit run app.py
